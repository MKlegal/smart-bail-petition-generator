# Smart Bail Petition Generator

**Pakistan's Most Advanced Legal Drafting Dashboard**

A professional legal drafting tool for Pakistani lawyers to generate bail petitions in exact court formats.

## 🚀 Features

- **4 Petition Types:** Post-Arrest (497 CrPC), Pre-Arrest (498 CrPC), Protective Bail & Cancellation
- **Exact Court Formats:** As filed in Pakistani courts
- **Professional Grounds:** 60-70 words each, extracted from successful petitions
- **Auto Brief Facts:** Urdu → English translation
- **Multi-Accused Support:** Add multiple accused
- **Live Preview:** Real-time updates
- **Word Download:** .doc file with proper formatting
- **100% Free:** No registration required

## 📦 Deployment

This is a static HTML/CSS/JavaScript application. Deploy to:

- **GitHub Pages:** Upload all files to a repository and enable Pages
- **Netlify:** Drag and drop the folder
- **Vercel:** Deploy with `vercel` CLI
- **Any Static Hosting:** Just upload the files
